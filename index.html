About me

I care about the engineering behind the interface: clear boundaries, safe data access, predictable workflows, and tests that protect important behavior.

My work combines modern React and Next.js interfaces with Python/FastAPI and database-backed services. Across my portfolio, I've worked on workspace-based SaaS, secure job tracking, task collaboration, and AI model evaluation workflows.

Rather than treating security and quality as afterthoughts, I build them into application behavior through server-side authorization, row-level security, automated integration tests, migration checks, and CI pipelines.

How I approach engineering

01 · Design for boundaries

Keep users, workspaces, roles, and data access clearly separated and enforce authorization on the server.

02 · Make behavior testable

Cover core workflows with unit, integration, database-policy, and end-to-end tests where appropriate.

03 · Ship with confidence

Use migrations, CI checks, containerized services, and deployment workflows to make changes repeatable.
