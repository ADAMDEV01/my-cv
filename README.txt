ADAM GOMAA HASSAN — VERCEL PORTFOLIo

Deployment:
1. Upload this folder to a GitHub repository, or import the repository into Vercel.
2. In Vercel, choose "Other" / static site if prompted.
3. No build command is required.
4. Set the output directory to "." (the project root).
5. Deploy. Vercel will provide a public URL.

The portfolio expands and reorganizes information from the supplied CV.
It does not invent project URLs. Add verified Live Demo / GitHub links to each
project card if you want those project names to link directly to their repos/demos.
